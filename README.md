# Публичная страница LoadLens

Эта ветка существует только для GitHub Pages. В ней один файл —
собранная диагностика, работающая целиком в браузере.

Страница собирается из `loadlens/web/` в ветке `main` командой
`python3 tools/build_web.py`. Править её здесь не нужно: изменения
перезатрутся при следующей сборке.
