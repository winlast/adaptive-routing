# Презентация

`LoadLens.pptx` — 22 слайда о том, что делает продукт, кому он нужен,
сколько это даёт в деньгах и где не работает.

Написана для чтения без докладчика: её отправляют и читают сами.
Слайды 1–16 — основная часть, без технических подробностей. Слайды
17–22 — приложение для тех, кто захочет проверить механизм.

Все числа в презентации взяты из файлов в [`../data/`](../data/) — по
тому же правилу, что и остальные тексты проекта: **ни одно число не
попадает в текст, пока не лежит в файле с данными.** Проверить любое из
них можно самостоятельно, см. [`../ПРОВЕРЬ_САМ.md`](../ПРОВЕРЬ_САМ.md).

Первая версия собиралась скриптом, чтобы числа не могли разойтись с
замерами. Окончательный вид файлу придали вручную, поэтому сборщик
здесь не лежит: он больше не воспроизводит этот файл, и публиковать
его значило бы вводить в заблуждение.
