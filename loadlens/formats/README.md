# Образцы форматов журналов

Короткие журналы настоящих форматов — по две строки в каждом. Нужны
для одного: убедиться, что инструмент читает то, что люди реально
приносят, и читает **правильно**.

Повод завести их был конкретный. Разбор требовал, чтобы время ответа
стояло в самом конце строки и ровно с тремя знаками после точки, — а
стандартный nginx время ответа не пишет вовсе. Apache, Cloudflare и
AWS не читались. Хуже всего вёл себя Caddy: его журнал разбирался
**молча и неправильно** — вложенное поле `request` принималось за
адрес, и из текста объекта вычитывались несуществующие параметры.
Тихая порча опаснее отказа, и поймать её можно только такой проверкой.

Во всех образцах запросы одинаковы намеренно: `/api/search?limit=10` за
12 мс и `/api/search?limit=900` за 740 мс. Значит, любой формат обязан
дать одни и те же числа, и расхождение сразу видно.

Проверка: `python3 loadlens/check_formats.py`
