# Диагностика в браузере

Один файл `index.html`, который открывается двойным щелчком и работает
без сервера. Посетитель перетаскивает на него журнал nginx и сразу
видит, насколько стоимость обращений различается внутри маршрутов.

**Журнал никуда не отправляется.** У страницы нет сервера: файл
читается и разбирается в браузере. Это не обещание в тексте политики
конфиденциальности, а свойство устройства — отправлять попросту некуда.
Для показа незнакомому человеку на его собственных данных это
решающее: журнал обращений показывает, кто что запрашивал.

## Сборка

```bash
python3 tools/build_web.py     # собирает index.html из шаблона и разбора
```

Исходники: `loadlens.js` — сам разбор, `index.template.html` — страница.
Собранный `index.html` содержит и то и другое плюс демонстрационный
журнал, чтобы страницу можно было показать, когда своего журнала под
рукой нет.

## Проверка

Браузерная версия обязана давать **те же числа**, что программа
командной строки. Иначе посетитель видит не то, что мы измеряли.

```bash
tools/test_web.sh
```

Скрипт прогоняет оба разбора на одних журналах и сравнивает результаты
по значениям, а затем проверяет, что собранная страница действительно
строит отчёт. Node в системе не нужен, проверка идёт в контейнере.

На двух журналах — демонстрационном и снятом с чужого PostgREST —
расхождений нет.

## Сбор отчётов

У нас нет журналов настоящих компаний, и это главный пробел в проверке.
Страница предлагает поделиться обезличенной сводкой, но устроено это
так, чтобы не требовать доверия:

- **ничего не отправляется само.** Пользователь видит готовый текст,
  копирует его и решает сам;
- **в сводку попадают только числа.** Ни адресов маршрутов, ни значений
  параметров, ни одной строки журнала. Это проверяется автоматически:
  `tools/test_web.sh` ищет в сводке `/api/`, `limit` и `http` и падает,
  если что-то из этого туда просочилось;
- отправка идёт обычным сообщением в GitHub, а не на наш сервер —
  его у нас нет.

## Где это пригодится

- Показать проблему на стенде: человек приносит свой журнал и за
  несколько секунд видит разброс на своих данных.
- Раздаточный материал: ссылка или QR-код ведёт на страницу, и ничего
  ставить не надо.
- Первый шаг внедрения: диагностика ничего не меняет в сервисе и не
  требует доступа к нему.
